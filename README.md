# AstroCHIA — Sitio Web Oficial

## Características del Sitio

- Diseño cósmico moderno con fondo interactivo de estrellas.
- Junta directiva oficial con perfiles y enlaces académicos.
- Directorio de científicas con búsqueda y tarjetas de información.
- Métricas de impacto animadas (+85 científicas, +15 países, fundada en 2018).
- Formularios integrados para registro y contacto.
- 100 % responsivo para móviles, tablets y escritorio.
- Rendimiento ultrarrápido y SEO optimizado.
